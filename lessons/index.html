怎样用这些课程

  1. 先读“学完本课，你能够”：知道这一课要带走什么。
  2. 对照教材原页：课程嵌入了教材的页面和插图。点图片可以放大。
  3. 动手玩演示：拨一拨、拖一拖、填一填，看数和图形怎样变化。
  4. 做自测题：每课最后有 3–5 道题。答错会显示解释。
  5. 问 AI 助教：右侧的 AI 助教读过整本教材和本课全部内容。可以选中一段话问它，或点图片、演示右上角的“问 AI”。
启用 AI 助教在终端运行 cd lessons && uv run --no-project python tools/serve.py，然后打开 http://127.0.0.1:8771/lessons/。模型是 DeepSeek（默认 deepseek-flash），走 DeepSeek 官方 API，按量计费。API key 放在 lessons/.env，只在本机服务里用，不进页面。直接双击打开 HTML 也能学，只是没有 AI 助教。
